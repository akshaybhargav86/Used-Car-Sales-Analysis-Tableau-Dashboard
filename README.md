# 🚗 Used Car Sales Analysis & Dashboard

## 📌 Project Overview

This project focuses on analyzing used car sales data to uncover key insights related to pricing, vehicle condition, mileage, and market value (MMR). The analysis is performed using Python, and an interactive dashboard is created in Tableau for visualization.

---

## 🎯 Objectives

* Analyze relationship between **MMR and Selling Price**
* Understand impact of **vehicle condition**
* Study effect of **odometer (mileage) on pricing**
* Explore **transmission and body type trends**

---

## 🛠️ Tools & Technologies

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* Tableau
* Jupyter Notebook

---

## 📊 Key Insights

* Strong correlation between **MMR and selling price**
* Vehicles with **better condition** tend to have higher prices
* Higher **mileage reduces selling price**
* Automatic cars are more common in the dataset

---

## 📈 Dashboard Features (Tableau)

* Sales trend analysis
* Price vs MMR comparison
* Condition-wise pricing distribution
* Transmission breakdown
* Interactive filters for deeper insights

---

## 📂 Files Included

* `car_prices.csv` → Dataset
* `Exploratory Data Analysis.ipynb` → Python analysis
* `Vehicle Sales Trends Dashboard.twb` → Tableau dashboard

## 🚀 Conclusion

This project demonstrates how data analytics can help understand market trends and pricing strategies in the used car industry.
